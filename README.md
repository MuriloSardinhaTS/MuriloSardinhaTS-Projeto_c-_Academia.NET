# 📌 T-Systems Projeto Curso – Windows Forms App

Aplicação desenvolvida em **Windows Forms (.NET)** como parte do projeto de curso.  
O sistema permite **registrar fornecedores** e realizar validações simples, garantindo que nenhum campo obrigatório seja enviado em branco.

---

## 🚀 Funcionalidades

### ✔ Registro de Fornecedores
- Cadastro de nome do fornecedor  
- Armazenamento em memória (ou futura integração com banco de dados)

### ✔ Validação de Campos
- Verifica se os campos obrigatórios estão preenchidos  
- Exibe uma **mensagem amigável** caso algum campo esteja vazio  
- Evita que dados incompletos sejam registrados

### ✔ Interface Simples e Intuitiva
- Layout padrão Windows Forms  
- Uso de caixas de texto, botões e labels para navegação clara

---

## 🛠 Tecnologias Utilizadas

- **C#**
- **.NET 10.0 (Windows)**
- **Windows Forms App**
- Programação orientada a objetos (POO)
